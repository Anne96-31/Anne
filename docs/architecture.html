排程與流程

.github/workflows/daily-report.yml

GitHub 免費主機每天開一台機器跑完全部步驟。④ 先刪掉超過 15 天的日報，再把 reports/ 推回 repo。

on:
  schedule:
    - cron: "0 0 * * *"      # UTC 00:00 = 台北 08:00
  workflow_dispatch:          # 可手動 Run workflow

- name: 產生日報
  run: python -m twdaily --top 800 --out reports
- name: 刪除超過 15 天的日報
  run: python -m twdaily.cleanup reports --days "$RETENTION_DAYS"
- name: 提交日報
  run: |
    git add -A reports
    git commit -m "日報：$(TZ=Asia/Taipei date +%Y-%m-%d)"
    git push
- name: 同步到 Notion
  env:
    NOTION_TOKEN: ${{ secrets.NOTION_TOKEN }}
    NOTION_DATABASE_ID: ${{ secrets.NOTION_DATABASE_ID }}
  run: python -m twdaily.notion reports/latest.md reports/latest.json

MACD 指標與選股條件

twdaily/indicators.py · twdaily/screener.py

這是「從低檔翻揚、MACD 轉正」的核心邏輯。參數集中在 ScreenConfig，可以自己調整。

# indicators.py：MACD(12, 26, 9)
dif = ema(close, 12) - ema(close, 26)
dem = ema(dif, 9)
osc = dif - dem                    # 柱狀體，由負轉正 = 翻紅

# screener.py
if avg_value < 3e7: return None    # 20 日均額 < 3,000 萬
if osc.iloc[-1] <= 0: return None  # 訊號已失效

gc = _last_cross_up(osc, 3)        # 近 3 日 OSC 翻紅
if gc and dif.iloc[gc] < 0 and range_pos <= 0.5:
    signals.append("低檔金叉")
zc = _last_cross_up(dif, 3)        # 近 3 日 DIF 站上零軸
if zc and (dif.iloc[zc-20:zc] < 0).sum() >= 10:
    signals.append("DIF翻正")

score = 2 * len(signals) + (close > ma20) + (vol_ratio >= 1.5) \
        + (40 <= rsi14 <= 65) + osc_rising     # 0–7 分

同步到 Notion

twdaily/notion.py

把 Markdown 轉成 Notion 區塊，補齊資料庫欄位，同一天重跑時先封存舊頁，最後清掉超過 15 天的頁面。沒設定 secrets 就自動略過。

def publish(md_path, summary_path, token, db_id, report_url):
    blocks = markdown_to_blocks(md_path.read_text())
    title_prop = client.ensure_schema(db_id)   # 補上 8 個欄位
    client.archive_same_day(db_id, date)       # 避免重複
    page = client.call("POST", "/pages", {
        "parent": {"database_id": db_id},
        "properties": page_properties(summary, title_prop, report_url),
        "children": blocks[:100],              # 一次最多 100 個區塊
    })
    # 其餘區塊分批 PATCH /blocks/{id}/children

# 發布後：日期早於 15 天前的頁面移到垃圾桶
Notion(token).prune_before(db_id, cutoff_date(15).isoformat())
